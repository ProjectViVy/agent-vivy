## Rules

- Archived documents are records. Append corrections; do not rewrite their
  claims.
- Path-only link updates are allowed when files move. When archiving a
  document, update the references in the same commit.
- Do not cite an archived document as the current contract. If a closed track
  restarts, create a new spec or plan and point back here for history.
