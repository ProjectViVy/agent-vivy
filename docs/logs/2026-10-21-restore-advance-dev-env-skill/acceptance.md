`.agents/skills/vivy-advance-dev-env/SKILL.md` before choosing a verification
venue. It uses a Linux-filesystem WSL checkout for the main Go/Node line and
keeps native Windows executable acceptance separate.

is unavailable. Missing stable infrastructure remains explicitly unknown or
refused; historical commands and ports are not presented as installed gates.

focused Git revert; no product database or installed environment was changed.
