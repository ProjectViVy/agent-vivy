# Developer acceptance

Public correction exposes current card revision and exact new evidence; stale CAS leaves the corrected revision/body unchanged. Tombstone removes that record from search and denies expansion after an owned process restart. Querying original reflection/update/delete receipts returns their original operation identity, target and revisions. Fresh authorized create mints a different record, keeping the old tombstone intact.

Controlled real ObserverHost replay reuses the actual accepted source and advances the actual task-owned cursor; changing event content is rejected. No additional model requests are used by capture/receipt recovery.

This is developer evidence only. Formal S04/S09, S08 recall, S05 ACTMEM continuity, S10 crash recovery, S11 degradation/isolation and Windows/live gates remain open.
