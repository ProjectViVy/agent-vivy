# Plugin I18N Contract Plan Acceptance

A reviewer can accept this planning cut when:

1. every task names exact files, inputs, outputs, commands, and expected
   results;
2. the plan promotes one shared catalog contract without adding a public Port;
3. the plan routes compiler work to P1, Host resolution to P6, and release
   proof to P9;
4. English fallback, Chinese development baseline, future packaged locales,
   literal namespace ownership, limits, canonical digest, and evidence states
   remain identical to the approved design;
5. functional phases remain explicitly unscheduled;
6. implementation ends with static checks, available local gates, exact
   iteration evidence, one focused commit, and a clean worktree.
