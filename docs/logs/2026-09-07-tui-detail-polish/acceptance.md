# 人工验收指引

## 怎么看（真机冒烟，待人工执行）

```
just run                 # 终端 1：控制面 127.0.0.1:8787
vivy tui --live          # 终端 2：连上后逐项过下面的清单
```

## 逐项清单（本 lane 交付的 7 特性）

| # | 特性 | 人眼判定 |
|---|---|---|
| 1 | F2 多行输入 | composer 里按 ctrl+j 换行输入多行 → 所有行都可见；超过 6 行后顶部行收成 `…`；每加一行 composer 随之长高（封顶 6 行），底栏不被顶飞 |
| 2 | F3 占位符 | 清空输入 → `::: ` 后出现暗色 `问点什么…  / 命令 · @文件 · !shell`；敲任意字即消失；审批弹窗挂起时不出现 |
| 3 | F4 大粘贴 | 粘贴 >2000 字符（或 >40 行）文本 → 附件行位置出现黄色 `⚠ 大段粘贴 · N 行 / M 字符 · …` chip；删到阈值下自动消失 |
| 4 | F11 busy 降亮 | 发送消息运行期间 composer 边框变暗灰；run 结束恢复模式色 |
| 5 | F1 spinner | busy 期间左下角显示 braille 转轮 + 已用时间（如 `⠸ 12s`，120ms/帧）；出错时错误文案优先；结束复位 |
| 6 | F12 状态行 | 有排队 turn 时右侧出现 `⏸ N queued`；窗口够宽时右侧还显示 host 与会话标题；窗口收窄时先丢标题、再丢 host、最后丢 queued |
| 7 | F6 滚动提示 | PgUp 翻进历史 → 左下角出现 `↓ end 回到底部`（离底远时为 `↑ 历史 · 下方还有 N 行`）；按 `end` 或 `G` 回到底部提示消失；空输入敲 `G` 生效、有草稿时 `G` 照常进草稿 |
