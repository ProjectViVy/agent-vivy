# Plugin I18N contract freeze acceptance

Date: 2026-09-09

The human owner approved the complete localization design, then explicitly
scheduled PLG-P1 and PLG-P2 for immediate implementation in a worktree. This
record converts the prior proposal/defer language into the approved normative
contract and records the clean-break execution order.

Acceptance does not schedule PLG-P3 through PLG-P9, does not authorize v0
compatibility, and does not move PLG-P6 runtime localization work into P1.
P1 owns parsing, validation, canonical hashing, evidence, and Manifest
projection; P6 owns Host resolution; P9 owns release conformance, removal,
and rollback proof.
