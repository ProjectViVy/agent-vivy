# Acceptance

A real App/provider read of an isolated random nonce reaches the next model
request with the exact result and call ID, produces the final answer, one
terminal event and returns idle (`TestToolResultReachesSecondModelRequest`, the
renamed existing D02 causal probe; its gate selector moves with it).

A native Eino tool result is committed before return. With only its derived
mapper acknowledgment paused, the next model request still carries the eligible
reminder. Durable completion and reminder scheduling remain mandatory; scheduling
failure retains its cause and blocks retry injection. Counts, parallel request
order, cached siblings, Work receipt retries, approval/resume, cancellation and
unknown-effect protection remain covered by production-owner regressions.

Absent factory selection yields false/nil accessors and no runtime/provider
import. Typed unwrapping never invokes a factory. Roll back the focused code
commit if needed; no data conversion or tenant Journal access is involved.
