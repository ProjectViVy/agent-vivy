# 验收：http_request 工具面

## 人视角（浏览器，http://127.0.0.1:3015）

1. 设置 → 网络工具分区：卡片下部出现「http_request 工具面」区块，
   显示配置默认白名单（localhost/127.0.0.1/::1）与配置超时（10 秒），
   无「已用设置覆盖」徽标。
2. 在白名单文本域填入 `api.example.dev`、`*.corp.dev`，超时改为 45，
   点保存 → 出现「已保存，下次启动生效」回执与「已用设置覆盖」徽标。
3. 刷新页面：白名单与超时回显保存值，徽标仍在（settings.yaml http 段持久化）。
4. 把超时填成 999 → 保存按钮禁用（1–120 钳制边界在 UI 先行拦截）。
5. 恢复默认值保存后，有效白名单/超时与配置一致（覆盖层与配置同值）。

## 后端生效

- settings.yaml 写入后无需重启：下一次 `http_request` 调用即按新白名单/
  超时执行（SetConfig 实时生效缝隙）。
- 配置默认（无覆盖层）行为与历史版本完全一致。
