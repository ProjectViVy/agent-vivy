# Acceptance

D02 is accepted through the owner-authorized scoped WSL route, with the single
optional ripgrep skip explicitly outside the changed D02/minimal contract.
The issue-91 index is the authoritative Story status record.

A fresh Linux-filesystem checkout can validate its source pin, compile kernel
wiring, build/inspect/boot the seven-module minimal artifact without pnpm or
frontend dependencies, and run affected D02 protocol checks. Lite still ships
the base Web shell. Selected UI compilation works without a prebuilt repository
dist. Windows and mounted WSL checkouts are directed to the correct venue;
missing DSNs or empty test selections cannot become success evidence.

Rollback is a focused source revert. This delivery changes no stored format,
production Journal, installed product or dependency pin. No release artifact
is published; full-product and native platform acceptance stay distinct.
