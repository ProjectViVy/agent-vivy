# Acceptance

A clean checkout bootstraps the exact lock revision, and the declared Go versions resolve the API used by the cognitive module. Local sibling modifications cause an actionable failure rather than silently changing the build.

The SDK's dependency graph includes metadata packages without optional owners. A minimal recipe can omit cognitive/memory/mask code; selected default recipes keep their existing capability inventory.

Use the final integrated repair verification for actual clean-source build and artifact pack/inspect evidence.
