# N2 — Optional notebook module + trusted actions

## Delivered

- **`vivy/notebook-core` module** (`internal/modules/notebook`): `Open(ctx, FactoryInput)` factory builds a `Bundle` over the N1 `notebookcontract.Store`; `Actions(scope, actor)` returns the `ScopedActions` facade (17 typed methods, mutations keyed by `operation_key`); `Close` disarms the bundle so later use fails. Module descriptor is sealed and reports the new closed Port `core/notebook-service@v1` (T1, AtMostOne, Conditional) plus 18 `std/control-action@v1` providers and the re-bound note tools.
- **Assembly seam**: `GenerateRuntimeAssembly` emits `NotebookFactory notebookcontract.Factory` plus `HasNotebookFactory()`/`NotebookFactoryValue()` only when a `core/notebook-service@v1` Provider is selected; omission produces closed accessors and zero imports. Factory binding requires the Port; provider requires the factory; duplicates rejected. `internal/app/assembly_notebook.go` resolves the bundle once per generation and gates `ScopeResolver.ForSession` through the session table (unknown session → `CodeNotFound`).
- **Trusted ActionHost** (`internal/actionhost/notebook.go`): `Notebook()` fails closed when unarmed or unauthenticated. Server-resolved identity decides origin: `RunID != ""` (only set by `bindPeerRunResult` from the durable RunStore) → workspace scope `ws.v1:<session>` + `run:<run_id>` agent actor; otherwise Home scope + `peer:<identity>` human actor. Foreign sessions denied. JSON input carries no scope/actor/origin fields — strict schemas (`additionalProperties:false` envelope + request) reject forged authority claims before decode.
- **Human-origin policy hook** (`internal/app/app.go`, `internal/runtime/policy.go`): `PolicyEvaluation` gained `Matched` (true only on explicit rule hit). `withNotebookHumanOrigin` relaxes an `ErrApprovalRequired` only when the decision came from the profile **default** (`!Matched`), the action owner is `vivy/notebook-core`, and the caller is human (`RunID == ""`). Explicit deny **and** explicit prompt rules stay decisive; in-run agent invocations keep frozen-run policy.
- **Note tools re-bound** via `notebook.ToolProviders()` (`list_notes`/`read_note`/`write_note`, 4 KiB bound, agent actor `tool:<id>`, content-hash default operation key for idempotent writes). `bindGeneratedTools` suppresses the legacy static binding for generated-claimed ids (ToolHost rejects duplicate ids). Module omitted → tools physically absent.
- **Durable exclusion provenance**: `Admit` stamps `ContentOrigin=notebook` + `ExcludeAutomaticIngest` on notebook ToolOperations; the message projector propagates both to `tool.finished` rows; `foldSessionHistory` taints summaries covering excluded content; the memory observer subscription skips excluded runs via `ExcludeRun = HasExcludedToolOperations` while still advancing the cursor. Paired migration `037_notebook_provenance.sql` adds `content_origin`/`exclude_automatic_ingest` to `tool_operations` and `messages` on both dialects; conformance case CN-45 asserts round-trip, `Reopen` survival, and no retroactive taint.
- **Recipes**: `default.vivy.yml` selects `vivy/notebook` + `vivy/notebook-core` + `vivy/notebook-tools`; `notebook-backend.vivy.yml` keeps actions/tools with no UI; `no-notebook.vivy.yml` excludes everything. `zz_default.go` regenerated; `default-generation.expected.json` updated.
