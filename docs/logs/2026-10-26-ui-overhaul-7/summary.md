# UI overhaul Block 7 — plugin UI modules onto the token contract

## What changed

Migrated every first-party plugin UI Module from hardcoded Tailwind palette
literals and legacy shadcn shim tokens onto the host semantic token contract
(`ui/src/styles.css`), so plugin surfaces follow the seven theme families
instead of carrying their own hues.

- **Palette literals removed (ratchet 29 → 0).** The masks identity chips
  (`MaskIdentity.tsx`) dropped `bg-blue-100 text-blue-600 dark:bg-blue-500/15 …`
  style quadruples for `bg-info-soft text-info-fg` (programmer),
  `bg-ok-soft text-ok-fg` (researcher), `bg-brand-soft text-brand` (writer),
  `bg-warn-soft text-warn-fg` (default/Star). Status notices and alerts moved
  to `bg-warn-soft`/`bg-ok-soft`/`bg-danger-soft` with matching `-fg` text;
  standalone status text uses `text-warn`/`text-ok`/`text-danger`. All
  `dark:` duplicates collapsed because semantic tokens adapt per
  `data-appearance` automatically.
- **Arbitrary text sizes removed (ratchet 45 → 0).** `text-[9px]`,
  `text-[10px]`, `text-[11px]` (concentrated in the workflow panes) map to the
  canonical smallest tier `text-2xs`; stock `text-xs`/`text-sm` map to
  `text-meta`/`text-ui`; headings map to `text-title`/`text-page`.
- **Shim/stock tokens normalized** across plugin leaf views
  (`bg-card`→`bg-raised`, `bg-muted`→`bg-sunken`, `text-muted-foreground`→
  `text-fg-muted`, `bg-destructive`→`bg-danger`, `border-border`→`border-line`,
  `bg-primary`→`bg-brand`, `bg-sidebar`→`bg-sunken`, etc.). Opacity suffixes
  (`/10`, `/30`, `/50`) were preserved so rendering stays pixel-identical;
  only the base token name changed. `hover:bg-accent`→`hover:bg-hover` while
  static `bg-accent`→`bg-selected`, matching the Block 6 kernel recipe.
  `ring-ring` / `ring-offset-background` were left alone: they are the focus
  tokens and have no canonical replacement.
- **Ratchet baselines zeroed.** `ui/src/theme/tokens.test.ts` plugins group now
  reports palette 0 / textSize 0 / hex 0 with empty file sets; the src group was
  already 0/0/0 from Block 6. The ratchet therefore fails on any new palette
  literal or arbitrary text size anywhere under `ui/src` or `plugins/**/ui/**`.

Files touched: 19 plugin UI sources across `vivy-masks-ui`, `vivy-memory`,
`vivy-notebook`, `vivy-persona`, `vivy-evolution`, `vivy-workflow`, and
`coding/session-tree`, plus `ui/src/theme/tokens.test.ts` and `docs/TODO.md`.

## Scope

- Plugin **original** sources only (`plugins/*/ui/*/src`). The staged copies
  under `ui/src/generated/ui/` are gitignored build artifacts regenerated by
  `scripts/stage-ui-assembly.mjs`; they were never hand-edited.
  `ui/src/generated/assembly.ts` (the one tracked generated file) is unchanged.
- Covers the seven registered extensions: `/persona`, `/evolution`, `/memory`,
  `/notebook`, `/masks`, `/workflows`, `/session-tree`.

## Explicitly not done

- **Workflow editor mobile clip** (toolbar ~830px wide, clipped by the frame's
  `overflow-hidden` `<main>` at ≤390px) is pre-existing and structural, not
  token-related; boarded as `UI-WORKFLOW-MOBILE-CLIP` in `docs/TODO.md` §0.1.
- The kernel shadcn primitives (`components/ui/*`) remain on the compat shim;
  shim removal is Block 9.
- No layout/width/flex classes were changed; this block is colour and type
  scale only.
