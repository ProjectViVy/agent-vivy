positive and maximum budgets without changing its retained record or operation
receipt. Zero returns 1000 Unicode characters, 7 returns 7, and 4000 returns4000;
the 5001-character fixture remains truthfully marked truncated.

Budgets -1, minimum int, 4001 and maximum int return `invalid_schema`, disclose no
fragments, and do not panic. Regression tests use actual native mutation/export
and retained operation lookup, not fake backend output. This is fixture-level
adapter verification and does not establish C2 source eligibility or activate
terminal projection.

The parent reruns the unchanged original reproducer on the immutable fixed
checkpoint. Actual Windows, browser, full repository CI, Task1b source navigation,
Task2 activation and product acceptance remain outside this fix qualification.
