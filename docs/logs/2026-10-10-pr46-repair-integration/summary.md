# PR #46 dependency and durability repairs

M1–M6 now share a reproducible dependency closure and existing durable authority. Laputa is pinned to reviewed full SHA `4b2bec2cc2ab3374b7ec1ab8d448e612c1e4db24`, with matching module revisions/checksums and source/Go bootstrap checks. Optional module catalog metadata no longer imports its implementations.

Queue replay publishes only after complete ordered replay, retries failures, and treats enqueue/dequeue/re-enqueue in event order. Full turn options and captured context survive RPC, admission, restart and execution. Existing transactional admission persists consumption and remaining tail before a driver starts. Mutation failures propagate. Compatible contiguous text turns can batch; different settings and captured attachments/context retain individual admissions. Resumed Eino phases retain the owning run context and atomically replace their steer cancellation handle.

Removal-only carrier-qualified controls in the existing Journal allow retained work on sealed runs to be removed or recalled, without reopening producer logs or adding a queue database/scheduler. Session deletion removes the controls. Full encoded DTOs that exceed the existing event payload limit are explicitly rejected before acknowledgement; accepted data is never clamped. GUI/TUI recovery drafts are manual editor state, not automatic local queues.

Mandatory model settlement failures reach Generate callers and stream consumers before EOF. Diagnostics cursors preserve position on append and detect replacement/truncation using opened-file identity and size. Paid cache maintenance calls use mandatory observation and usage/budget accounting; streaming warming defaults off, ineffective idle timers are removed, and explicit opt-in refresh is synchronous, bounded and coalesced. Prefix evidence refers to the same leading system/tool prefix. Unknown cache-write prices remain unknown; no live net-savings claim is made.

Each focused change has its own iteration record and regression evidence. Integrated verification and generated source-bound evidence are recorded separately. No schema migration, queue database, scheduler or background warming service was introduced. No push or deployment was performed.
