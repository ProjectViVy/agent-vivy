# Acceptance

- A clean checkout bootstraps the exact locked Laputa source, rejects a mismatched or dirty sibling, and builds headless and embedded products. Minimal and default SDK artifacts inspect to the same GenerationID as their binaries.
- A busy image turn with high thinking can be queued, survive a browser refresh, recalled and resent with its original preferences and image. The next actual model request receives them.
- Restart preserves ordered pending turns, including a later enqueue of a consumed ID. Storage failures leave pending work recoverable and are returned to callers. Fast completion cannot seal a run before its admission/tail markers exist.
- Cancellation after steering reaches the current phase, and cancellation retries after durable-store failure finish a parked run without overturning an answered question or decided approval.
- Success/EOF is not returned when mandatory model settlement failed. Appending diagnostic lines advances to the next unread line without a false gap.
- Default configuration performs no additional paid cache warm. Opt-in calls appear in usage and budgets; overlapping calls coalesce. Unknown cache-write rates do not become zero-cost estimates.

Limitations: queued DTO size is bounded by the existing event payload ceiling (64 KiB by default); oversized requests are rejected explicitly before ACK, reserving enough encoded space for later steer fallback and complete restoration. Live provider profitability was not measured. Windows diagnostics were cross-compiled, not runtime-tested on Windows.
