# Acceptance

An authoring agent receives a bounded Definition schema with only the child-task call node. A valid dependent graph can be proposed under a live parent and its normalized bytes and digest are returned. An integer-version descriptor, unsupported node, unknown config, write tool, ambiguous binding or excess literal input is rejected. Start reports that execution is unavailable until durable storage is installed and creates no workflow Run.

The inspector now starts from a valid Definition template and sends `definition` in propose/start requests. A complete runnable task graph is gated on S11-C through S11-E; this checkpoint does not establish end-to-end execution.
