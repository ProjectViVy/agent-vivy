# Acceptance

Deliver an old terminal payload through the real bound Garden capture sink, close/reopen that owner, then replay the same admitted Journal event using the updated provider. The original acceptance ID must be returned, without a new write or altered event ID. A direct changed-payload submission must still be rejected.

For new captures and restart, inspect both ingestion and canonical content; they must agree, include the random user fact and bind its actual run/session/role. Complete the unchanged formal Story gate separately.
