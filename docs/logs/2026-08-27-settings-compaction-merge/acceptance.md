# 验收视角（2026-08-27，设置 → 压缩并入通用）

## 用户如何看出它已生效

1. 打开应用，进入「设置」：顶部 Tab 列表不再出现「压缩」页签（原来在
   「网络」与「自进化」之间，带灰色「预览」徽标）。
2. 默认落在「通用」分区：在「聊天显示」卡片下方出现「上下文压缩」卡片，
   包含历史消息占用进度条、`最大 tokens / 压缩阈值 (%) / 保留最近消息`
   三个输入框，以及「执行压缩预览」「恢复预览默认值」两个按钮。
3. 修改任一压缩配置项（如把压缩阈值改为 50），页面底部反馈行立即更新
   （如「压缩阈值预览已更新。」）；点击「执行压缩预览」后历史消息占用
   变为「保留最近消息 × 240」，反馈行出现「已模拟执行一次上下文压缩预览。」。
4. 点击「恢复预览默认值」：三个输入恢复 8192 / 80 / 12，进度条回到默认
   状态，反馈行出现「压缩配置已恢复为预览默认值。」。
5. 深链 `http://127.0.0.1:3015/settings?tab=compaction` 不再报错、不再选中
   任何压缩页签，而是直接展示「通用」分区内容。
6. 其余预览分区（通道 / 网络 / 自进化 / 沙箱）外观与行为不变。
