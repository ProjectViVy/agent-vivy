# Acceptance

1. Open VIVY CODE in a wide terminal with enough right-rail rows to scroll.
2. Without clicking the right rail, place the pointer over it and use the wheel. Only the right rail moves.
3. Click or keyboard-focus the right rail, move the pointer over the chat transcript, and use the wheel. Chat moves while the explicit sidebar keyboard focus remains available.
4. Open a session picker, command overlay, or approval gate and use the wheel. No input leaks into the obscured chat or sidebar.
5. Resize to compact layout. Wheel input cannot mutate hidden sidebar state.
