# 验收

在 `http://127.0.0.1:3015` 打开“工具管理 → MCP”：

- 页面与全站其它页面同一视觉体系：白底卡片、标准按钮/徽章/开关，无粉色主题、无爱心与渐变装饰。
- 列表每行可一眼认出对象：名称 + 传输方式徽章 + 连接目标（命令或 URL）+ 工具数；开关即启用状态，无重复的状态文本。
- 可用动作都产生真实结果：
  - 开关切换立即持久化并同步头部计数；
  - “添加服务”必须填写与传输方式匹配的连接目标，错误在弹窗内提示且不丢输入；
  - 编辑可修改名称/传输/目标；删除需确认且不可撤销提示明确；
  - 导入/导出 JSON 往返命令与地址（支持 `tools.mcpServers` 嵌套结构）。
- 状态齐备：加载骨架、空列表（含导入/添加入口）、筛选空态（清除筛选）、行级忙碌锁定。
- 与旧版对比：旧的粉色渐变页、悬浮爱心、四张统计卡、`connected` 原始状态码、只能加不能删的残缺表单均已不存在。
