# Toolkit implementation

Implementation starts from the approved TK-P1 / TK-C1 package on TOOLKITS.
TK-01 adds strict native manifest parsing, deterministic identities, canonical
artifact hashing, immutable catalog values and narrow native Skill frontmatter.
No runtime owner has been connected yet. Subsequent Stories remain required.

TK-02 adds bounded local and pinned Git acquisition, immutable digest-addressed
objects, confined/hash-checked reads, staged promotion and recovery validation.
