# Acceptance

Date: 2026-08-27

产品/用户视角：打开 http://127.0.0.1:3015（split Vite + 真实控制面），
进入聊天页，检查输入框上方功能栏。

## 验收清单

1. **排布与内容**：功能栏从左到右为 —— 模式选择（智能体/计划/询问）、
   附件、思考开关、AutoDream、伙伴、权限模式（谨慎/智能/信任）、
   分隔线、历史、审批中心；不再出现「画图」与独立「智能」按钮。
2. **模式下拉**：点击「智能体模式」向上弹出三项（图标+标题+说明），
   当前项有勾选与高亮；选「计划模式」后触发器变为
   「⚙ 计划模式」，选「询问模式」变为「🧠 询问模式」；再次点击切换/关闭。
3. **思考下拉**：灯泡按钮点击弹出 自动/开启/关闭；「开启」为实心灯泡，
   选中项有勾选与高亮。
4. **权限下拉**：点击「智能」向上弹出 谨慎/智能/信任，选中后触发器标签
   更新（如「🛡 谨慎」/「✦ 信任」）。
5. **stub 反馈**：点击 附件 / AutoDream（分支图标）/ 伙伴（猫图标），
   输入框底部出现对应「暂未接入」提示条，约 1.8 秒后消失。
6. **历史**：点击时钟图标，右侧弹出「会话」抽屉（含搜索/新建/选择/
   重命名/删除），与右上角消息图标打开的抽屉一致。
7. **审批中心**：点击盾牌图标打开审批中心 Sheet；有待审批项时按钮右上角
   显示红底白字数字角标（如「2」），无待审批时隐藏。
8. **双语**：设置切换语言为 English 后，工具栏所有文案（含模式/思考/
   权限菜单说明）同步为英文；切回中文无残留。

## 失败判据

- 出现「画图」按钮或旧「智能」按钮、模式切换后发送仍不变、下拉无法
  开合、历史按钮仍弹提示条、审批中心角标非数字 —— 任一项即视为未通过。
