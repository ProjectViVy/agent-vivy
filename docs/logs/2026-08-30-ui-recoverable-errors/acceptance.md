# Acceptance · 前端可恢复错误

人在 `http://127.0.0.1:3015`（split Vite，不是 `:8787` 内嵌 UI）可以确认：

1. **控制面没起来**
   停掉后端后刷新页面：全屏「无法连接 Vivy」，说明要先启动 `:8787`，主按钮是「重试」。点重试会重新握手，不必整页刷新。后端起来后再点，应进入会话。

2. **缺 API Key**
   后端在、密钥未配时发送一条消息：对话区出现「模型密钥未配置」，并有「打开模型设置」链到 `/settings?tab=model`。输入框草稿还在。

3. **run 失败原因可见**
   一次对话以 `run.failed` 结束时，聊天区显示 payload 里的失败说明，而不是空白或只改 run 状态。刷新后重开该会话，历史失败原因仍在。

4. **发送失败不丢草稿**
   预检或 `turn/start` 失败时，输入框文字仍在，可以改完再发。
