# Acceptance

A human can accept this research deliverable when:

1. The report distinguishes pack-time assembly compilation, Go compilation/linking, and Eino runtime graph compilation.
2. It defines how internal and pluggable modules share descriptors/lifecycle while retaining different trust ceilings.
3. It maps current Tool, ToolWorld, Channel, Face, observer, provider, loop, world, context, storage, checkpoint, UI, and MCP capabilities.
4. It names the kernel-coupled authority boundaries and explains which implementations may still be internal providers.
5. It includes an Eino capability check against the repository-pinned version.
6. It gives a dependency-driven P0-P5 rollout and conformance matrix.
7. It does not claim implementation authorization or modify executable behavior.
