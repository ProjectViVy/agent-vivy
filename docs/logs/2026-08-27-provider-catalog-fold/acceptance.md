# 验收指引 — 2026-08-27 供应商目录折叠移植

以用户视角确认功能生效（开发环境：`just dev`，打开
`http://127.0.0.1:3015`）：

1. **看到 diva 的供应商目录**：进入「设置 → 模型」。"Vivy 模型配置"卡
   左侧出现供应商列表（OpenRouter、Anthropic、OpenAI、DeepSeek、Zhipu
   AI、DashScope…共 27 家常用供应商），顶部有「搜索供应商」输入框；
   当前运行配置对应的供应商行带「当前」徽标。
2. **不常用供应商默认折叠**：列表底部是虚线边框的「更多供应商」行
   （带数量 20 和箭头）。CherryIN、302.AI、PPIO、Together AI、Yi 等
   20 家默认不可见；点击该行展开/收起。
3. **搜索时折叠让位**：在搜索框输入 "yi" → 列表平铺 CherryIN 与
   Yi (01.AI)，折叠行消失；清空后恢复常用+折叠结构。
4. **选中供应商自动展开折叠**（若当前供应商在折叠组内，刷新后列表
   自动展开保证它可见）。
5. **选择即映射、保存走真实设置**：点 DeepSeek → 右栏出现其模型列表，
   下方表单变为 Provider=openai、Base URL=https://api.deepseek.com/v1、
   默认模型=推荐值；点某个模型只改默认模型；点「保存真实设置」后顶栏
   切换器显示 "DeepSeek | 模型名"。
6. **顶栏切换器跟随**：点顶栏模型按钮，下拉列出当前供应商的模型
   （当前项显示在「当前配置」，其余列在「XX 可选模型」），选择即保存。
7. **自定义组合不受影响**：手工把 Provider/Base URL 改成目录外的值
   （如私有网关），右栏显示"不在目录中"提示，仍按输入值保存。

密钥一如既往只由运行环境管理，页面不出现任何密钥输入。
