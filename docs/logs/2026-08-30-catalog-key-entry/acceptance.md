# 验收指引 — 2026-08-30 目录厂商 API Key 可填写

开发环境：`just dev` → `http://127.0.0.1:3015` → 设置 → 模型（Studio 会话
硬刷新亦可）。

1. **目录厂商输入框可编辑**：左侧点任意目录厂商（例如 DeepSeek），右侧
   API Key 密码框**可输入**；占位符为「sk-…（留空=应用时清除已配置密钥）」，
   下方提示「写入本机用户工作区（~/.vivy/settings.yaml）；值不会回传界面或
   写入日志。下一条消息即生效。」。
2. **失焦落盘、不回显**：填入 `sk-...` 后失焦（点别处），提示变为
   「已配置 API Key（值不会回传界面）」；刷新页面后输入框仍为空（写-only，
   值永不回传），但「已配置」提示仍在；自定义供应商列表**不出现**新的重复
   「DeepSeek」行。
3. **清除密钥**：清空输入框后失焦，该端点密钥覆盖被清除，「已配置」提示消失。
4. **防误操作**：只点进输入框再点出（不输入任何字符），密钥不被清除、也不新
   增条目。
5. **切模型即生效**：点击该目录厂商下任一模型，下一条消息即走该供应商且带
   上刚填的密钥（后端按端点解析）。
6. **自定义供应商行为不变**：选中自定义供应商时密钥可编辑/清除，「已配置」
   提示照旧。
7. **Mock 仍禁用**：选中内置 Mock 时输入框禁用，提示「内置 Mock 供应商无需
   API Key。」。
