# Acceptance

以用户视角确认（开发环境：`just dev` → `http://127.0.0.1:3015`）：

1. **首次向导**能填写显示名、Base URL、模型、API Key 并保存；跳过向导后聊天若未配置会提示去设置，而不是返回 `mock reply`。
2. **设置 → 模型**可以为目录厂商或自定义网关填写 API Key；保存后顶栏显示该模型，**无需重启**，下一条消息走新供应商。
3. **顶栏模型切换**只改当前选择，不把密钥清掉。
4. 若启动时设置了 `OPENAI_API_KEY`，设置页与向导显示只读（环境变量临时会话）。
5. 第二个 Vivy 进程指向同一工作区时启动失败，并说明工作区已被占用。
