# Review criteria

- Native content plugin authors write the Vivy format directly; no upstream converter/importer is a deliverable.
- A dedicated Plugins navigation/page is required, with installation, component inventory, lifecycle, consent and operation status.
- Existing Mask/Skill screens retain their authority and link to the package management surface.
- Delivery gates and acceptance scenarios include the UI; full v1 cannot be accepted on backend APIs alone.

These are design-review criteria, not implementation acceptance results.
