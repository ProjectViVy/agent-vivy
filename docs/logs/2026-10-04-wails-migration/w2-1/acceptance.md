# W2 iteration 1 — Acceptance

## Exit gate self-check (W2.md)

> The external host target demonstrably links generated assembly, accounts
> for local replacements and host/frontend content, rejects tampering, and
> passes VIVY CI.

- Links generated assembly: `TestPackGoHostSealedExternalArtifact` builds
  the fixture host under the generated `zz_default.go` overlay and seals
  `hostBuild`; `TestPackGoHostReproducibleGenerationID` shows the same
  generated bytes across staging paths.
- Accounts for local replacements: the consumer modfile rewrites every
  VIVY local replace to staged paths; external replaces escaping the
  declared closure are rejected; host replaces must stay in the staged
  host. Task 1 proves the closure is required (plain build fails).
- Host/frontend content: host commit/tree SHA256 resolved live into
  `hostBuild.source`; `frontend/` bytes bound via `assets.sha256` and
  staged once from the wrapper's frozen pnpm build output.
- Rejects tampering: source-hash mismatch, recipe drift, dirty release,
  output reuse rejected at pack; tampered frontend byte, sidecar manifest
  and embedded manifest rejected at Inspect.
- VIVY CI: `go test ./sdk/internal{,/assembly,/conformance}` green;
  `just ci` recorded in verification.md.
