# Acceptance

An enabled isolated DIVA profile can complete one actual source window with one canonical effect and matching durable receipt. Repeated bounded intermediate packets do not exhaust a single-packet aggregate budget. Authored graph limits and historical run policies retain their original ceilings.

Independent pending risks: arbitrary failures after effects still require failed-window retry/reconciliation verification; cognitive task text must not silently truncate its schema/input. These remain in the authorized local development queue.
