bind BML first, retain native provider results, and prohibit duplicate legacy writers.

## Global Constraints

GPT-6.1 Sol High. One backend projection sink per composition, no dual write or
backend replacement. Core retains originals; Laputa owns Recap. BML history/index
does not become a transcript authority. No wholesale Garden merge. DIVA/Mentle
contract compatibility is not installed-product acceptance.

## Review Focus

- Default composition currently includes BML and cognitive capture; both must not ingest the same LIFE experience.
- Pending old deliveries can try to write v2 into v3; reject and report policy skips without infinite retries.
- Legacy nonempty head cannot be silently reset to enable LIFE.
- Backend index lag/tombstone must not masquerade as deletion of core originals.
- Coding strategy must remain functional when optional old ACTMEM writes are unavailable.
