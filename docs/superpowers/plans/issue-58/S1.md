# S1: one durable Laputa Recap owner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** The existing ACTMEM Store atomically owns free-text Recap versions and coverage.
**Architecture:** Add v3 to the same Markdown owner, with immutable reachable history,
CAS and operation receipts. Expose it through the existing Garden bundle.
**Tech Stack:** Go, Laputa Markdown authority, OS locking, platform atomic file writes.
**Spec:** [design revision 3, C1](../../specs/2026-10-15-issue-58-unified-context-design.md).
**Epic/requirements:** Durable authority / R1,R6.
**Baseline/status/predecessors:** [index](index.md); S0's accepted C1 and subject identity contract; no ordinary-session LIFE selector.

## Global Constraints

GPT-6.1 Sol High. One Store/authority directory; no second database. All v3 writers
use CAS; legacy nonempty ACTMEM is never converted automatically. Originals are not
owned here. Reuse Laputa rules except the explicitly selected #58 policy refinement;
WORLD/persona boundaries remain. No new scheduler or reflection dependency.

## Review Focus

- Same directory opened by two instances/processes or symlink aliases must reject the second owner.
- Lost response after commit must replay the original receipt even after later revisions.
- File/dir flush failure after a replacement attempt is unknown, never a claimed rollback.
- Visibility is not a durable receipt: every fresh owner must recover the selected exact head before authoritative C1 service; live unknown returns zero data until Close/reopen/recovery.
- Windows missing-head negatives fail closed. Revision-zero Read is only uninitialized current state; an actual base-zero publication can return the first positive receipt. Neither permits premature S3 evidence retirement.
- Restore must preserve current coverage; clear must block stale summaries.
- Legacy v2 writes must never overwrite a v3 head, even on observer replay.
