Produce all C2 value types, error codes and function signatures. `DecodeNativeSkill` belongs in `internal/bundles` because parsing content is an owner concern; C2's signature is shared, not a requirement to put YAML in the contract package. Return structured codes with bounded field pointers, never raw private file content.

## Review focus

Duplicate JSON/YAML keys, case-folded path collisions, canonical argument ordering, invalid UUID/local IDs, and frontmatter that mounts tools must have explicit assertions.
