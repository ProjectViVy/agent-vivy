# TK-02 Native acquisition and immutable artifact store

> **For agentic workers:** Use `superpowers:executing-plans` for authorized execution; delegation requires authorization. Steps use checkbox syntax.

**Epic:** E1. **Requirements:** B4, B6, B8, B10, B11, B14.\
**Goal:** Acquire a native local/Git toolkit into a verified immutable object without executing its content.\
**Architecture:** Copy/extract into private staging, validate there, hash exact bytes, then durably promote the object; Core Storage activation is separate.\
**Tech Stack:** Go 1.26.4 standard filesystem/process APIs and existing host credential seam.\
**Spec:** [architecture](../../../architecture/VIVY-CONTENT-BUNDLES.md) sections 5–7/16; [TK-C1 C2–C3](contracts.md). **Baseline:** `1d6c9e236c11d929dd3423ed63272e88ed13e367`.\
**Status/dependencies:** [index](index.md).

## Scope and prerequisite output

Consume TK-01's accepted Manifest, InventoryEntry, path validation, canonical digest and native Skill parser. Create proposed `internal/bundles/{acquire,artifact,git_source}.go` with focused `_test.go` files. Produce `Acquire`, `OpenArtifact`, `ValidateArtifact`, `Artifact.ReadDeclared` as C3 specifies. No database writes or live owner replacement. No upstream conversion/ZIP/npm installer.

## Global constraints and review focus

Use a temporary fixture state root, never production data. Reuse existing authentication/credential infrastructure through callbacks; no shell-built Git commands, token-in-URL logging or Git hooks. Review source mutation during copy, links/parent traversal, cancelled acquisition, torn promotion, and corrupted retained objects. Do not accept a directory merely because it contains an upstream SKILL/plugin manifest.

- [ ] Run `go test ./internal/bundles -run 'TestAcquire' -count=1` to establish the failing behavior.
- [ ] Implement staged copy using root-confined filesystem operations and no-follow checks, enforcing total/per-file limits while streaming. Revalidate copied bytes and links before digesting; do not trust pre-copy stat alone. On Unix validate link count; provide equivalent Windows file identity/link validation through existing platform helpers or a narrow platform file. Reject unsupported confinement conditions, never silently weaken them.
- [ ] Implement `ReadDeclared` with normalized inventory lookup, UTF-8/text limits where requested, verified bytes and no arbitrary file fallback.
- [ ] Rerun the acquisition/read cases; assert cancellation removes only that operation's staging and preserves existing objects.

- [ ] Implement fsync/atomic same-filesystem promotion and directory durability using existing repository helpers where suitable. If the object already exists, verify its digest before reuse. No current symlink or mutable mirror is created.
