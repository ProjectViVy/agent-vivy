# N0 — Remove Automatic Notebook Injection Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: use `superpowers:executing-plans` for the recommended sequential execution, or `superpowers:subagent-driven-development` only if the owner selects that method. Use checkboxes to track implementation steps.

**Goal:** Ordinary conversations never enumerate or inject notebook content; existing explicit note tools continue working until N2 replaces their binding.
**Architecture:** Delete the legacy preamble projection at its source. Do not add a flag, replacement ContextSource, cache, or observer.
**Tech Stack:** Go, existing Service and prompt tests; pinned Eino adapter remains unchanged.
**Spec:** [Design](../../specs/2026-10-09-notebook-reports-design.md), sections 1, 2, 7, 12.
**Requirements:** NB-01, NB-07.
**Status/dependencies:** [Package index](index.md) is authoritative.
**Global Constraints:** Inherit the index constraints. Preserve historic messages and legacy note rows. No report or storage migration in this Story.
**Review Focus:** ordinary turns; resumed turns; remaining prompt callers; explicit tool compatibility; no mutation of historic data.
