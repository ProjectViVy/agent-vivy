## Interfaces and review focus

Keep `NodePanelProps.onChange(artifact:Artifact):void`. Read node.inputs, depend on node.inputs for external refresh, and patch node.inputs directly. Validate the parsed top-level value as a non-null JSON object with binding-shaped values (canonical fields: `literal`, `source`, `pointer`); backend remains the full semantic authority. Invalid JSON/shape retains draft/error and original artifact. task/tool_names stay untouched in config; no permissive migration of arbitrary config fields.

Review null/array/primitive input, reload/switching selected nodes, upstream pointer/reference validation, root input defaults and immutable published revision versus a later draft. Root-input wire behavior can be covered in runtime tests; do not expand UI into a new parameter editor to make that fixture pass.

The roundtrip fixture extends the existing two-node `a` → `join` definition. Author join.inputs as `{"literal_text":{"literal":"PG literal"},"root_text":{"source":"input","pointer":"/topic"},"upstream":{"source":"a","pointer":"/result"}}`. Supply root input `{"topic":"PG root"}` through the existing runtime start parameter; the scripted model for a returns `PG upstream`. Assert the joined child request contains all three resolved values and the immutable revision retains those exact bindings. INOFY's pinned `types.go` defines root source as `input`; `pointer:""` remains valid and must survive roundtrip. UI first-use proof covers literal/upstream through existing controls; runtime proof covers root input without adding a new UI product.
