Use current action IDs/typed client and operation receipts. Unit controls may delay/reorder replies to prove request identity, but browser wiring must use real action/backend state. Lost-response proof forwards the real request to commit once, discards only its reply, reconnects and recovers the same operation receipt; do not invent a fake success.
