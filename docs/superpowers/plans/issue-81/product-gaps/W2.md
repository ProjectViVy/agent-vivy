## Interfaces and review focus

Proposed `workflowLaunchParent(state:FaceStoreState):string|null` returns currentRun.id only when activeSessionId is nonempty, currentRun.session_id equals it and status is active. Page uses it for canRun; show localized "Start an active chat turn in this session to run a workflow." when unavailable. Preserve author/save/publish availability.

`FaceBridge.call('inofy.startRun',params)` rechecks immediately before RPC, overwrites parent_run_id from host, rejects with existing TransportError unsupported_feature when ineligible, and never forwards caller-supplied parent/session to override host authority. Retain a supplied valid operation_id for retry; existing generation/truncation behavior is outside this repair unless a concrete idempotency defect is demonstrated.

Review session changes between render/click, foreign caller parent, active run completing during admission, active/history display confusion and a lost acknowledgement retry. UI eligibility is advisory: backend race denial must remain visible.
