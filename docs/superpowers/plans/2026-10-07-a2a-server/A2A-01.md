# A2A-01 — TaskHost and Assembly Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or explicitly selected superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide the nonempty optional Channel task contract with correct Module identity and no regression to existing providers.

**Architecture:** Keep base Host unchanged; add the public value declarations and a grant-preserving optional wrapper. Derive Module ownership once from generated Assembly descriptors.

**Tech Stack:** Go 1.26.4, public Channel SDK, Assembly generator and existing Channel conformance.

**Spec:** [Design sections 3–5](../../specs/2026-10-07-a2a-server-design.md), baseline `58d1143` plus adopted G0 revision.

**Epic / requirements:** E1 / R1. **Status/dependencies:** [index](index.md#epics-and-story-authority).

## Global Constraints

Apply [package constraints](index.md#global-constraints). `std/channel@v1` remains `0..n`. No A2A SDK imports here; no new method on `channel.Host`; never hand-edit generated Assembly. An optional wrapper is constructed only around a real matching capability, not placeholder methods returning unavailable.

## Review Focus

RF2/RF4: a provider display ID cannot stand in for the Module grant identity; a typed-nil probe cannot be called as a live instance.

**Files:** Create (proposed) `sdk/port/channel/task.go`, `task_test.go`; modify `sdk/port/channel/channel.go` only to remove the approved empty `TaskLifecycle` placeholder. Verify existing provider modules `plugins/{telegram,dingtalk,discord,feishu,qq}`.

Copy declarations from the adopted design; do not create aliases with different names.

### Task A2A-01.2: Preserve capability and Module identity through wiring

**Files:** Modify existing `sdk/internal/assembly/runtime_generate.go`, `runtime_generate_test.go`, `channel_capability_test.go`, `internal/app/channels.go`, `channels_test.go`, `assembly_validate.go`, `app.go`; regenerate the affected Assembly through the existing generator path. Create no manually maintained parallel Module map.

**Interfaces:** Produce generated `RuntimeAssembly.ChannelModuleIDs map[string]string`, keyed by provider ID. Add `BindChannelsWithModuleIDs(providers []channel.ChannelProvider, grants map[string][]module.GrantBinding, configured config.Channels, moduleIDs map[string]string) ([]channel.Channel, error)`. Keep existing `BindChannels` callers valid. A `taskGrantedChannelHost` forwards the five TaskHost methods and discovery reader only when both wrapped capability and `channel.a2a` grant exist.

- [ ] **Step 1:** Write `TestChannelTaskHostGrantWrapper(t *testing.T)` plus generator fixture assertions:

```text
provider a2a -> Module projectvivy/a2a-server -> grant channel.a2a
missing/ambiguous Module mapping -> assembly/app validation error
grant absent or underlying Host lacks TaskHost -> wrapper does not assert TaskHost
authorized real task Host -> all five calls reach the underlying Host
typed-nil CapabilityTarget -> discovery succeeds without calling a nil receiver
ordinary Channel -> same preexisting capability set and behavior
```

- [ ] **Step 2:** Run `go test ./sdk/internal/assembly ./internal/app -run 'ChannelTask|TaskHost|ChannelCapability' -count=1`. Expect the identity/wrapper assertions to fail before wiring changes.
- [ ] **Step 3:** Generate the ownership map from resolved descriptors; thread it through app binding. Run `go generate ./internal/generated/assembly` for the checked-in default output. The wrapper checks its actual Module grant on calls; the underlying Host authenticates its private request context. The app wrapper must not expose or manufacture that private binding. Preserve bind-time/live CapabilitySource unwrapping.
- [ ] **Step 4:** Repeat focused tests and the existing Assembly generation integration suites. Expect deterministic generated output and compilation of the old five Channels. Run `just ci` for Story acceptance; empty test selection or skips are not a pass.
- [ ] **Step 5:** Commit wiring and Story evidence: `feat(channel): preserve task capability and module grants in assembly`.
