# A2A-04 — Journal Task Projection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or explicitly selected superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose authorized native tasks as bounded, deterministic snapshots and streams, including cancellation and ordinary-input state.

**Architecture:** Read committed Journal pages and reuse a pure native text reducer; notifications only wake readers. Host owns scope checks and public projection; runtime remains the sole effect owner.

**Tech Stack:** Go 1.26.4, native Journal/events.Bus, Channel SDK and existing app dependency injection.

**Spec:** [Design sections 5, 7–9 and 10 list bounds](../../specs/2026-10-07-a2a-server-design.md), baseline `58d1143` plus adopted G0 revision.

**Epic / requirements:** E1 / R4, R5, R8. **Status/dependencies:** [index](index.md#epics-and-story-authority).

## Global Constraints

Apply [package constraints](index.md#global-constraints). A snapshot's IDs/text/state/order must equal replay at the same committed watermark. No raw tool arguments/results, reasoning, credential names, paths or checkpoints are exported. Both interrupted states close the current stream but do not end the Run.

## Review Focus

RF2/RF3/RF5: authorization before projection, deleted ownership rechecked, terminal races replayed, and every scan/allocation budget enforced before materializing unbounded history.

**Files:** Create (proposed) `internal/channelhost/tasks.go`, `task_projection.go`, `tasks_test.go`, `task_projection_test.go`; modify existing `deps.go`, `channelenv.go`, `capabilities.go`, `internal/app/app.go`.

**Interfaces:** Implement the exact public TaskHost/TaskServiceInfoHost from A2A-01 on a task-capable environment wrapper only when dependencies are complete. Add `Deps.Tasks *TaskDeps`, with `Store storage.ChannelTaskStore`, `Journal storage.JournalPageReader`, `Submit func(context.Context, domain.ChannelTaskInput) (domain.ChannelTaskReceipt, error)`, `Cancel func(domain.RunID) bool` and `Subscribe func(domain.RunID) (<-chan domain.RunEvent, func())`. App supplies native Service callbacks and the existing bus; ChannelHost imports no runtime package.

Define a Host-private request binding in `tasks.go` with ModuleID, ProviderID, InstanceID, PrincipalID and AuthorizationRevision. A private context key plus `withTaskPrincipal`/`taskPrincipalFromContext` helpers is usable by A2A-05's HTTP boundary and same-package tests only. Stable InstanceKey is `encoding/json` of `[3]string{ModuleID, ProviderID, InstanceID}`. A binding is revalidated against current configured authorization on every operation; no public SDK setter exists.

### Task A2A-04.3: Snapshot-first subscriptions and honest reconnect

**Files:** Create (proposed) `internal/channelhost/task_stream.go`, `task_stream_test.go`; extend `tasks.go`, `task_projection.go` as needed for the same pure reducer, not another projection implementation.

**Interfaces:** Produce the concrete TaskStream behind `SubscribeTask(context.Context, channel.TaskSubscription) (channel.TaskStream, error)`. TaskUpdate contains exactly one snapshot/status/artifact and its opaque internal revision. Stable artifact ID is `text_` plus native message ID; full segments use append=false/lastChunk=true at the adapter. Public A2A clients do not supply the internal cursor.

- [ ] **Step 1:** Write `TestTaskStreamSnapshotTailRaces(t *testing.T)` with deterministic barriers for each boundary below, not sleeps:

```text
register wakeup -> capture H -> snapshot -> read H+1 tail -> wait
commit before/after each boundary => ordered committed projection, no live gap
bus drop / terminal close / missed publish => catch-up discovers committed tail
already terminal => unsupported; already interrupted => snapshot then EOF
input-required or auth-required update => deliver then EOF, Run still nonterminal
Close twice / canceled Next / slow reader / principal revoked => reader resources released
malformed/foreign/too-new internal cursor => cursor_invalid, no silent fallback
```

- [ ] **Step 2:** Run `go test ./internal/channelhost -run TestTaskStreamSnapshotTailRaces -count=1 -v`; expect missing stream/race behavior to fail.
- [ ] **Step 3:** Subscribe before reading snapshot pages; emit snapshot through H and read the tail before waiting. Advance through filtered events; on bus closure re-register before catch-up. Add a 1-second fallback tick for missed publish; neither bus close nor EOF proves success. Use synchronous Next/write backpressure with at most the configured notification slots. Validate cursor version/Run/sequence/ordinal and current scope; caps remain those in design 8/10.
- [ ] **Step 4:** Repeat with `-race -count=1`, plus the combined Host/native task suites and `just ci`. Expect snapshot/replay equivalence at H, no reader leak and no disconnect-triggered native cancellation. Standard wire reconnect means fresh snapshot convergence; exact replay requires the G0-approved extension plan if selected.
- [ ] **Step 5:** Commit stream behavior and Story evidence: `feat(channelhost): stream bounded journal task projections`.
