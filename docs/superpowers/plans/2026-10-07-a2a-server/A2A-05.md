# A2A-05 — Host HTTP Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or explicitly selected superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the optional Channel handler through an authenticated, bounded Host-owned listener with truthful lifecycle state.

**Architecture:** Reuse ListenHandler and the existing ChannelHost start/stop path. Host resolves credentials and injects the private principal binding; the adapter receives safe presentation data and an authenticated context.

**Tech Stack:** Go net/http, typed native configuration, existing credential resolver and Inspect.

**Spec:** [Design sections 5.2, 10–11](../../specs/2026-10-07-a2a-server-design.md), baseline `58d1143` plus adopted G0 revision.

**Epic / requirements:** E2 / R5, R6. **Status/dependencies:** [index](index.md#epics-and-story-authority). G1 acceptance and owner scheduling of G2 are separate prerequisites from writing this plan.

## Global Constraints

Apply [package constraints](index.md#global-constraints). G0 adopted minimum deployment 2026-10-07: require authentication on loopback; remote reachability is only through a TLS-terminating reverse proxy with a loopback backend — no direct Host TLS and no multi-principal endpoint in this release. Only the public card route is unauthenticated. Token references are operator configuration, never plugin secrets/grants.

## Review Focus

RF4: malformed URL/credential configuration, forged headers, revocation and slow writes must fail without exposing management routes or leaking credentials.

### Task A2A-05.1: Typed HTTP configuration and authenticated ingress

**Files:** Modify existing `internal/config/config.go`, config tests, `internal/channelhost/channelenv.go`, `deps.go`; create (proposed) `internal/channelhost/http.go`, `http_test.go`. Add credential/key-resolution coverage to the existing resolver's tests if the required key-reference path changes.

**Interfaces:** Add optional `ChannelEnvelope.HTTP *ChannelHTTPConfig`. Proposed values: `ChannelHTTPConfig{Listen, PublicBaseURL string; Principal ChannelHTTPPrincipal}` and `ChannelHTTPPrincipal{ID, TokenEnv string}` with exact YAML keys in design 10.1 — exactly one principal per endpoint; no TLS fields in this release. Use existing config validation entrypoints and CredentialResolver.Resolve; resolved credentials are Host-only. Private `(*Host).taskHTTPMiddleware(instanceID string, next http.Handler) http.Handler` is the single ingress wrapper; it consumes A2A-04's binding helpers.

- [ ] **Step 1:** Write config tests and `TestA2AHTTPIsolationAndLifecycle` ingress subtests:

```text
unknown typed field / missing principal block / TLS or multi-principal config keys => invalid
allow_from references the configured principal / missing token / grant / TaskHost => fail closed
public URL with userinfo/query/fragment/path => invalid; forged Host never changes card URL
nonloopback cleartext => invalid; loopback still requires valid allowlisted bearer
card GET without token => safe public info; every task RPC without token => HTTP 401
valid credential not allowlisted => 403; forwarded identity cannot override principal
body >256 KiB => 413 before admission; headers stripped before adapter sees request
```

- [ ] **Step 2:** Run `go test ./internal/config ./internal/channelhost -run 'ChannelHTTP|A2AHTTPIsolationAndLifecycle' -count=1 -v`. Expect current config/ingress to fail the new contract.
- [ ] **Step 3:** Implement strict validation, Host credential resolution and constant-time credential comparison, principal allowlisting, body bounds, safe correlation errors and private binding injection. Preserve A2A-Version but strip Authorization and untrusted forwarding/identity headers before SDK dispatch. Do not use `X-Forwarded-*` as authority. Keep presentation settings opaque to native config.
- [ ] **Step 4:** Repeat tests with token rotation and redacted logs/errors/Inspect. Expect token changes to preserve principal ownership and revoke prior streams when the listener restarts. Missing/bad auth must never reach SubmitChannelTask.
- [ ] **Step 5:** Commit ingress: `feat(channelhost): authenticate dedicated task HTTP ingress`.

### Task A2A-05.2: Listener lifecycle, bounded I/O and Inspect

**Files:** Extend `http.go`, `http_test.go`; modify existing `internal/channelhost/host.go`, `capabilities.go`, `host_test.go`, `internal/app/app.go` and its Channel lifecycle tests. No plugin opens a socket.

**Interfaces:** Add private `(*Host).startTaskHTTP(ctx context.Context, instanceID string, handler http.Handler) error` and `(*Host).stopTaskHTTP(ctx context.Context, instanceID string) error`. Consume live ListenHandler after provider Start, not a typed-nil discovery target. Effective Host policy supplies design 10 bounds; TaskServiceInfo derives public endpoint/skills/capabilities from live Generation/config truth.

- [ ] **Step 1:** Extend `TestA2AHTTPIsolationAndLifecycle` with deterministic listener/write doubles and a real loopback smoke:

```text
omitted / disabled / unconfigured => no listener or route
enabled => only POST /a2a and GET card; /rpc and unknown paths absent
bind failure or partial startup => resources rolled back, Inspect failed/inactive truth
10 requests/s burst20 per principal => bounded 429; no queue or Run created on rejection
public discovery => one aggregate listener bucket at 10/s burst20, bounded memory
2 streams/task,16/principal => excess rejected; Close releases slots
5s headers,15s individual writes,60s blocking wait,15s keepalive,10s shutdown drain
drain => new RPC 503; existing stream closed within bound; accepted Run not canceled
SSE survives beyond 15s total lifetime; slow individual write ends at its deadline
```

- [ ] **Step 2:** Run `go test ./internal/channelhost ./internal/app -run 'A2AHTTPIsolationAndLifecycle|Channel.*Lifecycle' -count=1 -v`; expect missing listener/limit behavior to fail.
- [ ] **Step 3:** Integrate start/stop into Host lifecycle with the states absent/inactive/starting/serving/draining/failed/stopped. Use the G0-proven bounded writer path, preserving Flusher and ResponseController; never set a 15-second whole-stream WriteTimeout. Enforce 1 MiB complete-frame limits before partial emission. Recheck authorization before writes/keepalive; no wildcard CORS. Discovery gets a bounded public rate bucket; RPC uses authenticated principal buckets.
- [ ] **Step 4:** Repeat focused tests with `-race -count=1`, native Channel lifecycle regressions and `just ci`. Inspect must distinguish compiled/granted/wired/started, report effective bounds and redact credentials/paths. Verify app startup failures close listeners in reverse ownership order.
- [ ] **Step 5:** Commit lifecycle and Story evidence: `feat(channelhost): govern task listener lifecycle and limits`.

## Acceptance and handoff

Return real loopback auth/lifecycle evidence and the private binding/writer behavior used by the adapter. The card view remains safe without a remote principal; task operations do not. No default endpoint is added to ordinary Generations, and no claimed throughput derives from the protective defaults.
