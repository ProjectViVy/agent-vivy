## Consumed and produced contracts

Consumes accepted v3 completion and C2/C3 durable result/approval contracts. Produces one direct path: durable tool outcome -> ordinary Eino ToolMessage -> next model request. Recoverable/refused results are classified at the tool boundary without a nudge state. Use D03 durable OutcomeStatus/OutcomeReason/OutcomeEffects with Result/Failure; completed-operation replay restores the exact classification from that row. Fatal/cancellation/native interrupts retain their existing propagation; never infer typed metadata from result text. Pre-claim refusal emits an honest refused/not_executed fact and no executed start.
Mandatory durability: admission/permission, approval, effect claim/outcome, final message and terminal. Optional transcript/status projection is derived and can replay. Hard budget/accounting invariants remain authoritative. The mapper consumes execution facts; it never grants continuation or synthesizes an execution start after completion.
