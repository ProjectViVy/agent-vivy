## Consumed and produced contracts

Consumes C1: live payload version 3, exactly `{"byte_len": N}`. `N` counts UTF-8 bytes for an emitted final completion, including an empty final; not run-wide. Preserve `tool.requested` as the tool-call phase boundary; no extra completion or budget charge for a tool-only/preamble response. Produces one aligned wire contract; preserve sequence/call correlation, replay boundaries, persisted final text and terminal ownership. Remove `digestModelRequest`, completion SHA accumulators and hash-error DTOs. Historical projection ignores digest keys. RPC replay normalizes supported historical v2 completion metadata to v3 before notifying strict Faces, preserving event sequence/byte count and stored Journal bytes. D00 enumerates older unsupported/raw-replay shapes and their explicit historical read alternative.
