## Boundary details

T3 owns the canonical sanitized selection encoder used later by T5. Exclude capture time and display-only labels from the digest; include ordered source identity, sanitized text, provenance, and truncation/redaction flags. Preview and read must use this one encoder. Cursor restart invalidation returns a recoverable reason; UI starts a new search, never attaches using a stale digest.
