## Boundary details

Distinguish receipt replay from recovery of a newly committed but never scheduled run. Duplicate requests return the original identity without launching a second engine. `EnsureForAdmission` returns `true` only for a newly created, root-validated, run-ID-named, non-symlink private directory; selected/local workspaces return `false` and are never removed. After an uncertain commit outcome, preserve the directory. Call `DiscardNewPrivateAdmission` only after a receipt check confirms non-commit. After a crash, reuse the existing startup recovery path; if it cannot safely resume a committed run, report its existing interrupted/unavailable state rather than silently creating a replacement. Test the crash immediately between database commit and engine scheduling.
