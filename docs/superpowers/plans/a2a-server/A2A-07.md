# A2A-07 — G2 Integration and Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans after A2A-06 acceptance and the owner schedules G2. Keep this Story open until every required gate has actual evidence.

**Goal:** Prove one real task end-to-end, safe B replay, and cold omission across packed Generations.
**Epic / requirements:** G2; R1–R6.
**Architecture:** Exercise official A2A client and an enhanced replay client against the same Host/Runtime, both SQL backends, local Face HITL and opt-in vs omitted packed artifacts. Record delivery and rollback evidence in the repo's standard iteration log.
**Tech Stack:** Go, official A2A Go client, SQLite/PostgreSQL, Vivy SDK verify/pack/inspect, `just ci`.
**Spec:** G0-approved design, [shared contract/status](index.md), accepted A2A-01 through A2A-06.
**Baseline:** main `3c4ed66826f5a40fd27dba0d9e208c55240a5955` + accepted predecessor revisions.

## Global Constraints

Never report G1/G2 accepted on source review or SQLite-only tests. The current `justfile` uses PowerShell; run `just ci` in a supported shell/toolchain, log environment failures accurately. Do not need credentials from the user for fixture-backed local tasks; owner will handle any real remote E2E requiring secrets. Do not enable A2A in default/lite or publish a public endpoint as a side effect of tests.

## Review Focus

Cross-principal/context task guessing; approval token leakage or remote approval; duplicate Run after lost response; replay losing an event during terminal/disconnect or deletion; default artifact accidentally retaining the optional SDK, settings or socket.

## Prerequisites and interfaces

Consume accepted A2A-06 standard Card/JSON-RPC/extension endpoints, A2A-03 stable public cursor and A2A-02 durable receipt on both backends. Need a configured local test bearer token, existing test Runtime with one tool-bearing Run, a local authorized Face for approval interaction, and a PostgreSQL test DSN. No live model API key is necessary for deterministic fake-model acceptance.
