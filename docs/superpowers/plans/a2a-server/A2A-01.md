# A2A-01 — Optional Task Port and Grant Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans after G0 is accepted and the owner schedules G1. Execute the checkboxes as separate reviewable actions.

**Goal:** Add an honest, protocol-neutral task capability for a selected channel without changing the base Channel interface.
**Epic / requirements:** G1; R1,R4,R5.
**Architecture:** Define one optional `TaskHost` on the Port; expose it through a wrapper variant only to modules with effective `channel.a2a`, and advertise task service only when an enabled provider consumes it and a real Host implements it.
**Tech Stack:** Go, `std/channel@v1`, module Grants.
**Spec:** G0-approved design and [shared contract](index.md); **index owns readiness**.
**Baseline:** main `3c4ed66826f5a40fd27dba0d9e208c55240a5955`; recheck head before execution.

## Global Constraints

No imports of A2A, Eino, internal Runtime or storage types into `sdk/port/channel`. No method added to `channel.Host`, `ChannelProvider`, or existing chat provider. `channel.a2a` must be effective, not merely requested. No product change until G0 accepted and owner schedules G1.

## Review Focus

Type assertion through `grantedChannelHost` must fail when grant is absent; a grantless module must never gain task access. A typed-nil capability target can be asserted but never called. An unconfigured adapter must not advertise a live task endpoint. Existing five chat channels must still compile and work.

## Prerequisites and contracts

Consume A2A-00's final Port signature, replay cursor rules and error mapping. Proposed Port shape, to be copied verbatim from the frozen G0 spec before work:

```go
type TaskHost interface {
    SubmitTask(context.Context, TaskRequest) (TaskRef, error)
    GetTask(context.Context, TaskQuery) (TaskSnapshot, error)
    ListTasks(context.Context, TaskListQuery) (TaskPage, error)
    CancelTask(context.Context, TaskQuery) (TaskSnapshot, error)
    SubscribeTask(context.Context, TaskSubscription) (TaskStream, error)
    ReplayTaskEvents(context.Context, TaskReplayQuery) (TaskStream, error)
}
```

`TaskRef` carries actual Run/Session IDs. Query includes Run ID and matching context. Stream returns ordered sanitized events and `Close`; verified principal comes **only** from Host context. If G0 instead freezes a smaller shared surface (e.g. replay as a second optional Port), update this and every downstream consumer together before marking Ready.
