# A2A-04 — Host Listener, Authentication and Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans after G1 scheduling and A2A-01/02 acceptance.

**Goal:** Let the selected A2A Channel publish exact HTTP mounts on a dedicated, authenticated Host-owned loopback socket.
**Epic / requirements:** G1; R1,R4,R5,R6.
**Architecture:** ChannelHost owns the listener, public URL/config truth, credential validation, request principal, resource bounds and shutdown. The plugin contributes handlers for declared routes; it never calls `net.Listen`. All task methods still enforce core ownership and Grant.
**Tech Stack:** Go `net/http`; existing ChannelHost/app config and credential resolver.
**Spec:** G0-approved design and [shared contract](index.md).
**Baseline:** main `3c4ed66826f5a40fd27dba0d9e208c55240a5955`.

## Global Constraints

Only A2A's configured enabled Generation gets a listener. Keep existing `127.0.0.1:8787` `/rpc` untouched; no public non-loopback bind, plugin-owned server or default mux. Bearer credential comes from the existing Host resolver keyed by `token_env`, never from plugin settings or client payload. A dangerous approval route is never mounted. `StartAll` currently skips failed channels; A2A failure must leave **no live route/socket** and an accurate unavailable note.

## Review Focus

Missing/empty token; crafted `X-Forwarded-*`/Host/Origin; attempt to bind `0.0.0.0`; route collision; shutdown while SSE is blocked; a stream connection whose HTTP request ends while Runtime keeps running.

## Prerequisites and interfaces

Consume A2A-01 grant-aware `TaskHost` and G0's finalized optional mount interface (`HTTPMounts` returning `[]HTTPMount{Method,Path,Handler}`) plus A2A-02's verified task ownership. Produce one Host-managed mux/listener available to A2A-05 and a verified principal in request context. G0 owns exact server-side config fields; proposed `channels.a2a` envelope includes `enabled`, single `allow_from`, `token_env`, `listen_address` and `public_url`. `public_url` is advertised only if it matches the configured exposure mode and endpoint actually bound.
