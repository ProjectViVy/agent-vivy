# G1-01 Host and Workspace Seams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or, when authorized, superpowers:subagent-driven-development. Track the steps below with checkboxes.

**Goal:** Give ACP the minimal governed input, error and safe-text contracts, while preserving existing Faces.
**Architecture:** Extend the Face SDK additively. Keep workspace lookup and redaction inside the existing Host/Core; the adapter receives a per-run sanitizer closure and typed RPC errors.
**Tech Stack:** Go 1.26.4, Face Port, authenticated Control, existing internal/logging redaction.
**Spec:** [Design](../../specs/2026-10-07-acp-stdio-face-design.md), sections 6, 9, 12.4-12.7.
**State/dependencies:** [Index](README.md#story-index--authoritative-state-and-dependency-data), E1 / R2,R3; requires accepted G0-02.
**Global Constraints:** No ACP types in sdk/port/face; no new base Host method, secret registry or direct plugin filesystem access.
**Review Focus:** RF-1 and RF-3; preserve nil input for existing callers and empty-workspace fallback.

## Files and interfaces

Modify existing sdk/port/face/face.go; internal/app/facehost.go; internal/rpc/protocol.go; internal/rpc/control.go.
Extend existing face_test.go, facehost_test.go, protocol_test.go and project_context_test.go beside those implementations. Add internal/app/facehost_text_test.go for focused privacy coverage.

Proposed additive SDK definitions:

~~~go

    TextSanitizer(context.Context, string) (TextSanitizer, error)
~~~

Core producers:
- func (e *Error) RPCErrorCode() int in internal/rpc/protocol.go; preserves existing Error() and cause behavior.
- func (e *faceEnv) TextSanitizer(ctx context.Context, runID string) (face.TextSanitizer, error).
- func (h *controlHandler) projectContextRoot(ctx context.Context, sessionID string) (string, *Error), a private resolver used by startTurn for context_paths.
- A private run-workspace lookup callback on faceEnv, wired from the owned App. It returns the canonical path from a.service.Workspace after authenticated run/get validation. Do not export raw roots through the SDK.

Consumers: G1-02 uses Options.In and unchanged FaceProvider; G1-03 asserts TextPresentationHost at construction and inspects structural RPCErrorCode via errors.As.
