> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or, when authorized, superpowers:subagent-driven-development. Track the steps below with checkboxes.

**Goal:** Produce one inspectable restricted ACP artifact and prove the complete user path without changing the default product.
**Architecture:** The compiler selects the finished adapter and isolated entrypoint. Existing source-hash and conformance machinery binds tests to what ships; scripted process tests precede a real-client smoke.
**Tech Stack:** Existing SDK verify/pack/inspect commands, conformance reproduction, just ci, accepted IDE/client and configured test provider.
**Spec:** [Design](../../specs/2026-10-07-acp-stdio-face-design.md), sections 12.1, 12.10 and 13.
**State/dependencies:** [Index](README.md#story-index--authoritative-state-and-dependency-data), E2 / R1-R6; requires G1-02 and G1-05.
**Global Constraints:** No placeholder source hash in a build; no passing attestation without executed tests; no full ACP compliance claim; no merge/deploy is included.
**Review Focus:** RF-1/RF-5 on the actual process, default artifact omission and a real client without form support.
