# G1-02 Isolated Face Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or, when authorized, superpowers:subagent-driven-development. Track the steps below with checkboxes.

**Goal:** Build a generic Face executable with private runtime state, clean stdout and no Web/TUI implementation.
**Architecture:** Extract storage-only allocation from codeface, select session-aware composition for ACP, and reuse the generated Face Provider. The Recipe entrypoint selects the build target; no launcher imports plugins/acp.
**Tech Stack:** Go 1.26.4, existing app lifecycle, Recipe compiler, packer and sealed Generation manifest.
**Spec:** [Design](../../specs/2026-10-07-acp-stdio-face-design.md), sections 4, 10, 12.1, 12.9.
**State/dependencies:** [Index](README.md#story-index--authoritative-state-and-dependency-data), E2 / R5,R6; requires G1-01.
**Global Constraints:** entrypoint defaults to gateway; face has exactly one Face and no UI. Existing codeface remains fixed-local. No manually edited generated assembly.
**Review Focus:** RF-5, retention of resident state, and help/inspect modes that must not start ACP.

## Files and interfaces

Proposed: internal/faceprocess/private.go, launch.go and their tests; cmd/vivy-face/main.go, main_test.go; sdk/internal/face_entrypoint_test.go.
Modify existing: internal/codeface/launch.go and launch_test.go; internal/app/facehost.go and facehost_test.go; cmd/vivy/main.go; sdk/internal/assembly/{compiler.go,compiler_test.go,manifest.go,manifest_test.go}; sdk/internal/frontend_v1.go; justfile headless-compile.

Proposed contracts:
- faceprocess.Prepared { Config config.Config; SharedSettingsPath string; InstanceRoot string }.
- func PreparePrivate(cfg config.Config, namespace string) (Prepared, error), allowing only internal constants code-instances and face-instances; storage/log allocation only.
- func Run(ctx context.Context, cfg config.Config, opts face.Options) (face.Result, error).
- func Main(args []string, in io.ReadCloser, out io.WriteCloser, errOut io.Writer) int.
- func app.RunSelectedFaceWithAppOptions(ctx context.Context, cfg config.Config, opts face.Options, appOpts ...app.AppOption) (face.Result, error). Within package app, reuse one App and its a.assembly.Face; never construct a second App merely to discover the Provider.
- Recipe.Entrypoint string with json/yaml entrypoint tags; AssemblyPlan.Entrypoint and GenerationManifest.Entrypoint carry the compiler-resolved value. CanonicalRecipe normalizes empty to gateway before hashing; Inspect validates the sealed value. Older inspected manifests without the field retain gateway interpretation.
