# VIVY Web and TUI I18N Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver complete English and Chinese localization for the Web and
TUI faces using one backend-authoritative locale, a Generation-embedded
default, global-workspace persistence, and plugin-ready translation units.

**Architecture:** A small Go locale package owns `en|zh` validation and
precedence. `vivy-sdk pack` embeds the build default in both the executable and
`generation.json`; `settings.yaml` may override it globally through a narrow
RPC. Web and TUI hydrate from that RPC and render through locale-aware
catalogs. Plugin catalog metadata and SDK validation remain a proposal.

**Execution ruling (2026-09-09):** Tasks 1–7 are implemented and reviewed
through `1b1fdd3`. Task 8 is deliberately deferred: the rejected v0 SDK is not
an approved owner/artifact target, and PLG-P1's v1 Module-ID/artifact foundation
is still unscheduled. The historical Task 8 steps below are not authorization
to extend v0 or promote proposal metadata. Task 9 uses direct UI executables,
records Go/just exit 127 once each, statically checks CI wiring, and commits as
`docs(i18n): document locale precedence and verification`. See the design's
final implementation status for observed evidence; complete Web/TUI I18N and
its acceptance criteria are not waived.

**Tech Stack:** Go 1.25, JSON/YAML, JSON-RPC, React 19, TypeScript 5.8, Vite 7,
Vitest, Bubble Tea, Node.js validation scripts.

**Spec:** `docs/superpowers/specs/2026-09-09-i18n-design.md`

## Global Constraints

- English (`en`) is the compiled product default.
- Exactly `en` and `zh` are accepted in this release.
- `VIVY_DEFAULT_LOCALE` in a gitignored root `.env` is a developer/build input;
  an existing process environment variable wins over the file.
- A sealed Generation embeds its default and does not depend on a later `.env`.
- A global-workspace `settings.yaml` locale override wins over every default.
- Web localStorage is a cache only; the backend response is authoritative.
- User text, model output, tool output, Journal content, and workspace files are
  never translated.
- Plugin catalogs are explicit package/Recipe inputs and own only
  `plugin.<module-id>.*`; core owns `vivy.*`.
- Every behavior change is test-driven and every task ends in a focused commit.
